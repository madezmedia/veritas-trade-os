## Decisions Made

### Architecture
- **Chose:** 3-agent swarm (Sentry → Executioner → Auditor)
- **Rationale:** Separation of concerns = verifiable trust
- **Tradeoff:** Slightly more complex vs single agent

### Differentiation
- **Focus:** Verifiable trading via EIP-712 + ERC-8004
- **Moat:** Network effects (other teams query our registry)
- **Position:** "Trust layer" not just "trading bot"

### Tech Stack
- **Models:** Gemini 2.5 Pro (strategy) + Flash Lite (execution)
- **CEX:** Kraken CLI
- **DEX:** Aerodrome (Base Sepolia)
- **Trust:** ERC-8004 registry
